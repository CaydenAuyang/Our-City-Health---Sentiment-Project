# Our-City-Health---Sentiment-Project (redirect)

This repository exists only to redirect old URLs to the renamed project.

**Active project:** [OurCityHealth](https://github.com/CaydenAuyang/OurCityHealth)
**Live demo:** [caydenauyang.github.io/OurCityHealth](https://caydenauyang.github.io/OurCityHealth/)

The original project was renamed in 2026. GitHub Pages does not auto-redirect
content URLs after a repo rename, so this repo serves a small set of static
HTML pages that forward every path under the old name to the matching path
under the new name.

If you arrived here by clicking a link to
`caydenauyang.github.io/Our-City-Health---Sentiment-Project/...`, you'll be
redirected automatically.
